关于本合集

本合集由 Mavis (Mavis Code Agent) 整理与维护， 面向 SCI 遥感论文作者、研究生、行业应用工程师，覆盖数据采集全链路：

①

通用 SCI 库

Figshare / Zenodo / Dryad / PANGAEA / OSF / Dataverse / Mendeley / IEEE DataPort / ESSD / GMD —
论文 DAS 必填。

②

国家官方数据

NASA / USGS / ESA / EUMETSAT / NSIDC / NOAA / CEOS / JAXA / JMA / KARI / ISRO / INPE / DLR / CNES / ASI / ROSHYDROMET —
全球主要对地观测机构。

③

中国国家 + 行业

12 个国家科学数据中心 + CRESDA / ChinaGEOSS / ScienceDB / 风云 / 水利部 / 海洋局 / 生态环境部 / 农业农村部 / 地震局 / 气象局 / 林草局 —
中国全行业覆盖。

④

科研院所 + 高校

中科院空天院 / 地理所 / 青藏所 / 南湖所 / 东北地理所 / 武大 / 清华 / 北师大 / 同济 / 中大 / 中国地大 / 华东师大 / 南大 / 中农大 —
国产 SCI 高被引数据集主要来源。

⑤

AI/ML + 商业

HuggingFace / Kaggle / Roboflow / paperswithcode / Planet / Maxar / ICEYE / Capella / 吉林一号 / 珠海一号 / 海丝一号 —
AI 时代主流数据集平台。

⑥

跨库检索 + 工具

re3data / FAIRsharing / DataCite / Google Dataset Search / OpenAIRE / EOSC —
统一检索 + 工具链（GDAL / GEE / Planetary Computer / STAC / earthaccess / geemap）。

维护与更新

本合集每月更新一次；新增平台、新发射卫星、新政策会同步在 附录 G 中。 如需引用，请按 网址 + DOI 双重验证最新可用性。

使用建议

  • 找某类数据：看左侧目录定位到对应部分（13 个主题）
  • 投稿时 DAS 引用：看 附录 D 模板
  • 跨库检索：第九部分 re3data / FAIRsharing / Google Dataset Search
  • 自动化下载：附录 F 工具链
  • 国外官方：第六 (日本) / 第七 (其他国家) 部分
  • 国内研究机构：第三 / 第五 / 第十一部分
  • AI 论文数据集：第十部分
